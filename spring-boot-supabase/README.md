# Spring Boot Supabase Example

Visit Article - [Spring Boot Supabase Example](https://mkyong.com/spring-boot/spring-boot-hello-world-example/)

## Things you will use:

* Spring Boot 4.1.0
* Java 25
* Maven 3.9.6
* Supabase (free plan)

## How to start

```bash
$ git clone [https://github.com/mkyong/spring-boot.git](https://github.com/mkyong/spring-boot.git)

$ cd spring-boot/spring-boot-supabase

$ set the environment variable SUPABASE_DB_URL

$ mvn spring-boot:run
```
